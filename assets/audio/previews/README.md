# Áudios dos previews

Grave uma frase de 16 a 20 segundos no mesmo arquivo:

- `0:00–0:08`: clean, sem o IR;
- em `0:08`: ligue o IR sem interromper a execução;
- `0:08–0:16/0:20`: mesmo ganho e sem reverb, delay ou efeitos adicionais.

Use exatamente o nome de arquivo exibido no card da página `/preview/`. Depois de copiar o MP3 para esta pasta, adicione o id correspondente à lista `PUBLISHED_TONE_PREVIEWS` em `equipment-data.js`. O card troca automaticamente o aviso pelo player.
