# Imagens de equipamentos

- `originals/` preserva os arquivos baixados das páginas oficiais dos fabricantes.
- Os arquivos WebP na raiz desta pasta são as cópias otimizadas usadas pelo site.
- `sources.json` registra página oficial, URL exata da imagem, formato e tamanho do arquivo.
- `scripts/download-product-images.ts` refaz o mapeamento e o download.

As marcas e imagens pertencem aos respectivos titulares. Os arquivos são usados para identificação editorial dos equipamentos. Antes da abertura comercial da loja, confirme também os termos do programa de afiliados e as permissões de uso de mídia de cada fabricante ou varejista.
