# Loja-curadoria e futuros links de afiliado

Os botões atuais abrem uma pesquisa na Amazon Brasil com `s=price-asc-rank`, mostrando primeiro os anúncios de menor preço disponíveis naquele momento. Isso evita publicar um preço fixo que fique desatualizado.

## Antes de ativar afiliados

1. Abra cada busca e escolha o anúncio considerando preço total, frete, prazo, reputação do vendedor, revisão do produto e política de devolução.
2. Gere o link no painel oficial do programa de associados.
3. Adicione ao registro do equipamento um campo `affiliateUrl`.
4. Faça `amazonSearchUrl` usar `affiliateUrl` quando existir e manter a busca ordenada como fallback.
5. Atualize o aviso de transparência para dizer que links qualificados podem gerar comissão.
6. Revise periodicamente links quebrados, produtos indisponíveis e revisões antigas.

Não copie preço, nota, foto ou promessa de entrega para o site sem um processo de atualização autorizado. O catálogo foi desenhado para continuar útil sem esses dados voláteis.
