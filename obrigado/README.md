# Página padrão de obrigado

Rota: /obrigado/

- Confirmação com aviso de que as informações de acesso chegarão por e-mail.
- Convite baseado no popup de downloads/download-experience.js para postar um antes/depois com IR e marcar @mvavebr.
- Cards para /violao/, /bass/, /guitar/, /completo/ e /guia/.
- Conteúdo estático, disponível sem JavaScript; estilos-base compartilhados com /guia/page.css.
- Noindex/nofollow; não incluída no sitemap.
- A página não valida pagamentos nem libera acessos: o envio permanece a cargo da plataforma de venda.

Para usá-la no funil, configurar https://mvave.com.br/obrigado/ como destino após a compra, depois da publicação.
